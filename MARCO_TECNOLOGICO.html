El desarrollo de la plataforma se fundamenta en un conjunto de tecnologías modernas de código abierto, seleccionadas por su capacidad para manejar concurrencia, transmisión de datos en tiempo real y compatibilidad multiplataforma. A continuación, se describen las herramientas que conforman el ecosistema del proyecto.

1. Entorno de Ejecución y Servidor (Backend)

Node.js y Express: Node.js es un entorno de ejecución multiplataforma basado en el motor V8 de Google, diseñado para construir aplicaciones de red escalables mediante un modelo de entrada/salida sin bloqueo y orientado a eventos. Express opera como un marco de trabajo minimalista sobre Node.js, facilitando la creación de la Interfaz de Programación de Aplicaciones (API RESTful) que gestiona la lógica de negocio y las rutas del sistema.

TypeScript: Es un superconjunto tipado de JavaScript que añade tipado estático opcional al lenguaje. Su inclusión en el backend y frontend reduce drásticamente los errores en tiempo de ejecución al validar las estructuras de datos (como el formato de una alerta o un paquete GPS) durante la fase de compilación.

2. Gestión de Datos y Base de Datos

MongoDB y Mongoose: MongoDB es un sistema de base de datos NoSQL orientado a documentos, el cual almacena la información en estructuras BSON (similares a JSON). Esta flexibilidad permite manejar estructuras de datos variables. Mongoose actúa como una capa de Modelado de Objetos de Datos (ODM), proporcionando validación de esquemas y traducción estricta de objetos entre Node.js y la base de datos.

Redis: Es un motor de base de datos en memoria que funciona como almacén de estructuras de datos clave-valor. En la arquitectura propuesta, se emplea primordialmente como un intermediario (Message Broker) para el adaptador de Sockets, permitiendo sincronizar eventos en tiempo real entre múltiples instancias del servidor.

3. Desarrollo Frontend (Web y Móvil)

React y Vite: React es una biblioteca de JavaScript para construir interfaces de usuario interactivas mediante componentes encapsulados que gestionan su propio estado. Para la compilación y empaquetado del cliente web se utiliza Vite, una herramienta de construcción que ofrece tiempos de recarga ultrarrápidos y una gestión de dependencias optimizada para entornos de desarrollo modernos.

React Native y Expo: React Native es un framework que permite compilar aplicaciones móviles nativas (iOS y Android) utilizando el mismo paradigma de React. Expo es un ecosistema de herramientas construido alrededor de React Native que facilita el acceso directo a las APIs nativas del dispositivo (como el módulo de GPS, notificaciones y cámara) sin necesidad de configurar código específico en lenguajes como Java o Swift.

Zustand: Es una biblioteca de gestión de estado minimalista para React. Se utiliza para mantener el estado global del Centro de Mando (por ejemplo, el inventario de alertas activas), asegurando que los componentes se actualicen de manera eficiente sin la complejidad arquitectónica de otras soluciones como Redux.

4. Comunicación Bidireccional y Geoprocesamiento

Socket.io: Es una biblioteca de JavaScript que habilita la comunicación bidireccional y en tiempo real entre clientes web/móviles y servidores. A diferencia de las peticiones HTTP estándar, Socket.io mantiene una conexión abierta, lo cual es imprescindible para recibir las coordenadas GPS de una alerta en fracciones de segundo.

Turf.js y Leaflet: Leaflet es una biblioteca ligera de código abierto para la creación de mapas interactivos. Turf.js, por su parte, es un motor de análisis espacial avanzado diseñado para JavaScript. En conjunto, Turf.js realiza operaciones matemáticas complejas (como la generación de isócronas o cálculo de distancias) y Leaflet se encarga de renderizar estos polígonos sobre la cartografía base en la interfaz del operador.

5. Procesamiento Multimedia

MediaMTX y FFmpeg: MediaMTX es un servidor de medios versátil que actúa como un puente de transmisión. En combinación con FFmpeg (una colección de bibliotecas para manejar multimedia), el sistema es capaz de recibir señales de cámaras de videovigilancia convencionales (vía RTSP) y reempaquetarlas al vuelo hacia protocolos modernos orientados a la web (como WebRTC), posibilitando la visualización simultánea de múltiples cámaras en el panel web de control.
